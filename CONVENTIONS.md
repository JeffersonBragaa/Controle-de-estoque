# Convenções do Projeto

## Tecnologias

- Next.js (App Router)
- TypeScript
- CSS
- Prisma
- PostgreSQL

## Regras Gerais

- Utilizar TypeScript em todos os arquivos.
- Evitar código duplicado.
- Reutilizar componentes sempre que possível.
- Não alterar funcionalidades fora da TASK atual.
- Sempre manter o código organizado e legível.
- Utilizar nomes claros para variáveis, funções e componentes.
- Comentar apenas quando realmente necessário.
- Antes de adicionar uma dependência, verificar se ela é realmente necessária.

## Estrutura

- Componentes reutilizáveis em `/components`
- Lógica de negócio separada da interface.
- Utilizar Server Components sempre que possível.
- Client Components apenas quando necessários.

## Qualidade

Todo código entregue deve:

- Compilar sem erros.
- Não quebrar funcionalidades existentes.
- Seguir boas práticas de segurança.
- Estar pronto para produção.
