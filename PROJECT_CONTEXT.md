# Estoque Inteligente

## Tecnologias

- Next.js 15
- TypeScript
- PostgreSQL
- Prisma
- Tailwind
- Shadcn UI

## Objetivo

Sistema SaaS de controle de estoque para pequenos empreendedores.

Público-alvo:

- Loja de roupas
- Loja de tênis
- Loja de celulares
- Assistência técnica
- Papelarias
- Pequenos mercados

Prioridades

1. Simplicidade
2. Performance
3. UX
4. Segurança
5. Escalabilidade

Arquitetura

- App Router
- Server Components
- Server Actions
- API Routes apenas quando necessário

Regras

- Não adicionar dependências sem necessidade.
- Sempre reutilizar componentes.
- Nunca quebrar funcionalidades existentes.
- Sempre utilizar TypeScript estrito.
